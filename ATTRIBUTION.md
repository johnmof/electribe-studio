## Electribe Studio derivative

Electribe Studio is based on Only2000000iqiscool/e2sample-manager, commit
f8d10508827174530abf6ba3e74488d37b3abb3e, under GPL-3.0-or-later.
Windows support, range moves, pattern editing/remapping and the revised interface
were added in this derivative. Original license and credits remain applicable.

Pattern layout facts were cross-checked with rafamj/elecmidi, maks/elfer and
bangcorrupt/hacktribe. No firmware, factory samples or upstream pattern banks are
redistributed. New sample playback metadata follows Oe2sSLE's documented fields.

Dependencies: Python (PSF), NumPy (BSD), SoundFile (BSD), libsndfile (LGPL),
sounddevice and PortAudio (MIT), PySide6/Qt (LGPL/GPL). Available package license
notices are included in the Windows bundle under third-party-licenses.
